#📝 Pastes App (Frontend Only)
A simple Pastebin-style web app frontend where users can create, view, and manage text pastes. Built with React and styled using Tailwind CSS.

Features:
- Create new pastes with a title and content

- View a list of existing pastes

- View individual paste details

- Delete a paste

- Responsive and minimalist UI

Note: This project is frontend-only. You can connect it to any backend API or mock the data locally for testing.

##Tech Stack
React – for building UI components

Tailwind CSS – for styling

React Router – for navigation

Redux Toolkit (optional) – for state managemen
